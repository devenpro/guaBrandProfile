What changes between today and these mocks

  • Wizard: monolithic form → 6 stepped pages with progress bar, growth-phase branching, surfaced custom instructions, scrape review styled as scannable cards.
  • App shell: three-pane (sidebar → list → detail) → two-pane (sidebar → full page). Middle "list of fields" pane is removed entirely.
  • Identity (and every category): 7 list cards each requiring a click → one scrollable page with every field visible, inline editing, per-field AI menu.
  • Dashboard: didn't exist → new landing view showing completion across all 8 sections plus brand-at-a-glance.
  • AI prompts: generic context dump → structured Brand Brief with growth-phase guidance and cross-stage references (e.g. voice references identity mission).

Open layout questions

  • Should the dashboard hero use a brand-color gradient (as mocked) or a neutral card? The gradient adds personality but competes with the brand's own colors when we add brand-color tokens later.
  • Per-field AI menu (sparkles → dropdown) vs. always-visible "Improve / Shorter / Longer" inline buttons. Menu is cleaner; inline is faster.
  • TOC on the right of category pages (as in Identity mock) — useful on long pages, redundant when a category has < 5 fields. Show only conditionally?
  • "Resume editing" pill on dashboard — is "last opened page + last opened field" the right granularity, or just "last opened page"?
