V1

Original 6-step wizard

The first redesign pass — monolithic AI run at the end, blank discovery Qs, scrape review as its own step. Replaced by the per-stage flow above.

What changed since v1

  • AI execution model: one upfront mega-prompt → lazy per-stage calls, each with cumulative context. Voice references the approved Identity mission verbatim; Competitors references Market positioning.
  • Discovery Qs: blank textareas → AI-pre-filled drafts the user reviews. Saves typing and seeds higher-quality downstream prompts.
  • Custom instructions + description: two separate fields → one "brand dump" textarea as the anchor context for everything.
  • Per-phase UI variants: three different dashboards / menus / wizard flows → one UI for all phases. Phase only modifies prompt depth and content richness.
  • Competitors: buried inside the Market stage → dedicated stage with its own review, edit-as-cards UX.
  • Phase upgrade: rewrites everything silently → confirmation modal + the same review screens the user used in setup. Adds depth without overwriting approved content.

Open questions to discuss before Phase 1

  • Stage cancel mid-draft: should it revert to the previous stage (keep approved Identity but discard the in-flight Voice draft) or strand the user on an empty Voice screen?
  • Discovery follow-up cap: hard-limit to 3, or let the AI propose up to 5 if it sees enough gaps?
  • On phase downgrade, do we hide the extra depth (e.g. extra personas) or delete it? Hiding lets users upgrade back losslessly.
  • Competitor list: cap at 5 with "more" toggle, or scroll freely?
  • Should the AI-drafted brand dump itself be regeneratable (after edits, "tidy this up")? Cheap nice-to-have, but it muddies the "user's words" anchor.
